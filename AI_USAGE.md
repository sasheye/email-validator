# Использование ИИ

При разработке использован OpenAI Codex в диалоге с пользователем.
ИИ подготовил регулярное выражение с комментариями, проверки причин ошибок,
обработку файловых исключений, консольное меню, тесты и документацию.

## Реальные запросы пользователя

1. «извлеки текст из файла и проанализируй»
2. «Давай сделаем план проекта»
3. «Давай начнем делать проект, также делать комиты»

Исходное задание: кейс 9, страницы 15–17 предоставленного PDF.
В диалоге согласован план консольного валидатора с поддержкой `+`.

## Примеры полученного кода

Регулярное выражение и его пояснения находятся в `validator.py`.
Разбор причин ошибок реализован в `validate_email()`.
Обработка ошибок кодировки, JSON и файлов — в `main.py`.
Сохранение истории через временный файл — в `history.py`.

## Проверка результата

Автоматические проверки находятся в папке `tests` и запускаются командой
из README. Они включают все примеры из задания и дополнительные ошибки.

Для сдачи приложите скриншоты фактического диалога и запуска программы.
Скриншоты в этот репозиторий пока не добавлены. Этот документ описывает
реальное использование ИИ; отдельные запросы на каждую функцию не выдуманы.
