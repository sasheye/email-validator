# Валидатор email

Учебный проект по кейсу № 9. Требуется Python 3.10 или новее.
Внешние библиотеки не нужны.

## Запуск

Откройте терминал в папке проекта:

```sh
python3 main.py
```

Меню позволяет проверить один адрес, обработать файл и посмотреть последние
20 проверок. Для пакетной проверки можно указать `examples/emails.txt`,
а для нового отчёта — `results.txt`. Относительные пути считаются от папки,
из которой запущена программа. Существующий отчёт не перезаписывается.

Входной файл: UTF-8, один адрес на строку. UTF-8 с BOM поддерживается.
Пустая строка внутри файла считается некорректным адресом. Полностью пустой
файл вызывает понятную ошибку. Пробелы в адресах не удаляются автоматически.

История хранится в `history.json` рядом с программой и сохраняется между
запусками. Запись содержит время с часовым поясом, email, результат и причину.
Повреждённая история не перезаписывается: сначала сохраните её копию,
затем исправьте или переместите файл.

## Правила

Локальная часть: латинские буквы, цифры, `_`, `-`, `+` и точки между
непустыми группами. Ровно один `@`. Домен содержит минимум одну точку;
его части состоят из латинских букв, цифр и дефисов. Дефис не может стоять
по краям части домена. Последняя часть — 2–6 латинских букв.
Регистр букв не ограничен. Пробелы и последовательные точки запрещены.

Это правила учебного задания. Проверка подтверждает формат адреса;
существование домена и почтового ящика не проверяется. DNS, графический
интерфейс и пользовательские регулярные выражения в эту версию не входят.

## Проверка

```sh
python3 -m unittest discover -s tests -v
```

Тесты покрывают примеры задания, ошибочные адреса, пакетную обработку,
отчёт, повторное сохранение истории, пустой и отсутствующий файл,
неверную кодировку и повреждённую историю.

## Файлы проекта

- `main.py`: меню и сообщения пользователю.
- `validator.py`: регулярное выражение и причины ошибок.
- `file_operations.py`: пакетная обработка и отчёт.
- `history.py`: история JSON.
- `tests/`: автоматические проверки.
- `AI_USAGE.md`: сведения об использовании ИИ.

История и отчёты исключены из Git. Посмотреть коммиты: `git log --oneline`.

Тестовые файлы также можно запускать напрямую из редактора или терминала:

```sh
python3 tests/test_validator.py
python3 tests/test_files.py
```
